# 🛍️ OnlineStore  

**OnlineStore** — an educational iOS project written in **Swift**, using **SnapKit**, **Firebase**, and a custom **DesignSystem**.

---

## 📖 About the Project  

**OnlineStore** is a demonstrative app showcasing the fundamentals of an online shopping experience, powered by the **Platzi Fake Store API**.  

With this app, users can:  
- **View products**  
- **Add products to cart**  
- **Wishlist items**  
- **Proceed to payment**  

> This app was created purely for educational and demonstration purposes.

---

## Technologies Used  :
- **Swift** — core development language  
- **SnapKit** — for programmatic Auto Layout  
- **Firebase** — for backend & authentication  
- **Custom DesignSystem** — shared UI components  
- **Platzi Fake Store API** — product data source
